# Utterform 1.0 — acceptance

What Jonas checks on the installed **1.0.0-rc.1** before it is released as 1.0.0. Install
commands are in [the candidate's notes](../releases/v1.0.0-rc.1.md). Each line is one thing
to try; a failure goes into an issue (or the chat) with the platform and, where there is
one, the diagnostics reference from Settings → App.

The settings folder (to start on a clean profile, rename it first and back afterwards):
Linux `~/.config/software.jli.utterform`, Windows `%APPDATA%\software.jli.utterform`,
macOS `~/Library/Application Support/software.jli.utterform`.

## Every platform

**Upgrade and first start**
- [ ] Install over 0.8.0: settings, key and history are kept, no assistant appears.
- [ ] Clean profile: the assistant opens; Cloud with a key (Create key ↗ opens the browser),
      Finish → dictation works.
- [ ] Clean profile: On this device, Base model downloads on Finish → dictation works offline.
- [ ] Clean profile: Skip on the first screen → main window, nothing changed.
- [ ] While the assistant is open, the dictation key and a second launch only bring it forward.

**Dictation**
- [ ] Dictation key in another app: text arrives at the cursor.
- [ ] Tray: red dot while recording, green for five seconds after delivery (also with sounds off).
- [ ] Settings: search finds a row, a change applies at once, a new dictation key works at once.

**Text actions**
- [ ] Provider ChatGPT (Codex login): Polish or Email runs, quickly.
- [ ] Context: select (Linux) or copy (Windows, macOS) an email, say "reply that …", the reply
      arrives at the cursor.
- [ ] Per app: rule Thunderbird (or another app) → Email; the dictation key there shows
      "Utterform · Email — for …", elsewhere the window's action.

**Audio files**
- [ ] Folder button / `O`, and dropping a file on the window: text in history and clipboard.
- [ ] A real WhatsApp voice message from the phone.
- [ ] "Open with → Utterform" in the file manager; the default player stays as it was.

**Start at login**
- [ ] Switch on, sign out and in: Utterform starts in the tray, no window. Switch off: gone.

## Linux (asus16, Omarchy)

- [ ] Setup → Defaults → Dictation → Utterform: Alt+Space dictates, holding Right Alt
      dictates while held, Super+D keeps working.

## Windows (CBZIT004 or another PC)

- [ ] Start at login (issue #40): after switching on, both values exist —
      `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\Utterform` and
      `…\Explorer\StartupApproved\Run\Utterform` — and Utterform starts after sign-in.
- [ ] Explorer → Open with lists Utterform for an `.m4a` or `.ogg`.
- [ ] The app in front is recognised for a per-app rule (Outlook, Teams or a browser).

## macOS (MacBook Air M2)

- [ ] The DMG opens without a Gatekeeper warning, also offline (stapled ticket).
- [ ] Microphone and Accessibility prompts appear once; typing at the cursor works.
- [ ] Finder → Open With lists Utterform for an audio file.
- [ ] The frontmost app is recognised for a per-app rule (Mail).

## Then

All boxes ticked or the rest accepted by Jonas → bump the installers, README and notes from
`v1.0.0-rc.1` to `v1.0.0`, tag `v1.0.0`, verify the assets, and send the new WinGet
submission. A fix found here → `v1.0.0-rc.2` first.
