# Utterform 0.2.0 Beta

Speak once. Shape the text — and keep your last thought within reach.

## What's new

- **A living recording surface:** large, smooth violet/blue ambient shapes respond to microphone volume behind stationary controls. The recording indicator and timer stay clear; reduced-motion preferences are respected.
- **Click / clack:** soft synthesized start and stop cues, outside the captured audio. Optional in Settings; no external sound files or network calls.
- **Designed menus:** action, file format, and recent-text selectors now share the app's design, including keyboard navigation.
- **Recent texts:** the latest 100 completed texts survive restarts, including clipboard-only results. A compact selector shows short local titles, not dates. The displayed text stays visible during the next recording.
- **Copy again:** an elegant copy button and `Ctrl+Shift+C` / `Cmd+Shift+C` copy the displayed text (latest by default).
- **Omarchy:** no native title bar in an Omarchy/Hyprland session. Other desktops, Windows, and macOS keep standard window controls.
- **Background capture:** switching apps, minimizing, or closing to tray no longer discards the recording. A native ten-minute watchdog stops capture independently of WebView timers; processing starts when the WebView is available again.
- **Cross-platform downloads:** GitHub Actions builds Linux, Windows, Apple Silicon macOS, and Intel macOS binaries. Every main-branch build also offers downloadable CI artifacts.

`SHA256SUMS.txt` covers every binary and the Linux installer. The Linux build deliberately uses system libraries, not an AppImage runtime.

Omarchy installation/update (quit the old running app first):

```sh
curl -fsSL https://github.com/jli-software/utterform/releases/download/v0.2.0-beta.1/install-linux.sh | sh
```

On macOS, open the DMG and drag Utterform into Applications. These beta builds are unsigned and not notarized; Gatekeeper may require approval in **System Settings → Privacy & Security → Open Anyway** after your first launch attempt. Windows SmartScreen may also warn. Only approve downloads obtained from this repository and check their hashes. No system-wide security settings need to be disabled.

## Privacy and compatibility

History is **local and unencrypted**, stored in the OS app-local-data directory. Titles use the first words of the text without an additional AI request. Disable future history or explicitly clear existing history in Settings; clearing does not delete exported files or clipboard contents. No audio history is kept.

Existing settings, API keys and downloaded models are preserved. History and sound feedback are enabled by default. History writes are atomic; persistence failures leave the current result visible with a warning rather than silently losing it.

Recording begins only on explicit Start. Shortcuts remain **window-focused**, not global hotkeys. Tray Quit discards active audio and exits. Automatic Omarchy theme switching, global shortcuts, auto-update, signing and notarization are not part of this beta.

Automated validation includes Rust tests, Clippy, Svelte/TypeScript checks, component tests, production-browser GUI tests with synthetic IPC, and native builds on all four targets. This is an early beta: those checks do not replace interactive microphone/speaker, permissions, tray, and desktop testing on your own macOS/Windows/Linux setup.
