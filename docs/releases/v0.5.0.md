# Utterform 0.5.0 — Signal

White. Graphite. Your voice in motion.

Signal gives Utterform a quieter, more precise identity: crisp controls, fine dividing lines, a geometric U mark and no coloured gradients or glowing panels. Light, dark and system themes cover the whole interface, including settings, prompts, model controls and history menus.

## The recording still moves

A flowing monochrome contour field responds to the existing microphone level. Quiet speech produces gentle movement; louder speech adds depth. Pause freezes the field. Reduced-motion preferences keep it still, and animation stops while the window is hidden. The native recording, pause/resume, ten-minute limit and background dictation are unchanged.

The recording controls are now a compact **Record / Finish** button beside **Pause / Resume**, with the timer above. Action selection, clipboard/file/typing targets, latest text and copy remain close at hand, including in the smallest 360 × 400 window.

## One identity, on every platform

The new mark is embedded in the Windows executable, setup and uninstaller, the Linux application/menu icon, the macOS application bundle and tray icons. Linux installation atomically replaces the previous icon and refreshes its local icon cache. Windows setup and removal notify Explorer that shell icons have changed; they do not delete caches or restart Explorer.

Use the normal installer to update. Product identifiers, install locations and user-data handling stay the same, so existing settings, prompts, keys, history and local models remain available. Windows retains Tauri's stock upgrade/uninstall flow, including running-app checks and its explicit opt-in for deleting application data. Leave **Delete app data** unchecked if you want to keep your data when uninstalling.

## Same tools, new interface

GPT Transcribe and local Whisper, editable prompts, vocabulary, shortcuts, dictation sounds, clipboard, file export and typing at the cursor remain unchanged. The small daily duration shows audio represented in today's retained history, not a lifetime usage counter.

## Downloads

Get [Utterform 0.5.0](https://github.com/jli-software/utterform/releases/tag/v0.5.0). Stable filenames are unchanged:

- Windows: `utterform-windows-x86_64-setup.exe` or portable `utterform-windows-x86_64.exe`.
- Linux: `install-linux.sh` and `utterform-linux-x86_64-system.tar.gz`.
- macOS Apple Silicon: `utterform-macos-aarch64.dmg` or `utterform-macos-aarch64.app.zip`.

Windows builds are unsigned; macOS bundles are ad-hoc signed, not notarized. Verify downloads against `SHA256SUMS.txt`. OS shell/pinned-shortcut icon caches may take a moment to refresh; the packaged resources and installed desktop icon are replaced immediately.
