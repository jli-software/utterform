# Utterform 0.7.12 — Visual delivery confirmation

On October 20, the regular release was explicitly authorized without a preview
acceptance gate; installed-desktop testing will follow after release.

The tray icon keeps its small red dot during recording (including pause). When
processing and all requested outputs succeed, the same dot turns green for five
seconds, then disappears. This visual confirmation works with sounds switched off
or an inaudible speaker. Stopping the microphone alone is not success: processing
is unbadged; cancellation, failed transformation and incomplete output do not turn
the icon green. A new recording replaces green with red immediately. Live dictation
also requires nonempty delivered text and no processing/output failures (history is best-effort).

Both Windows/macOS native tray icons and Linux's StatusNotifierItem (including
the native fallback) use the same colors and expiry policy. No settings migration,
additional polling, focus change or extra delay before the next recording is added.
Only one five-second expiry task is retained; old callbacks cannot overwrite a
newer recording or success status. Existing sounds remain unchanged.

Windows installation can use `install-windows.ps1`, which verifies the
published NSIS setup against `SHA256SUMS.txt` before opening the interactive
installer. Windows builds remain unsigned.

## Installed-desktop checks

Quit the installed app before installing the update. With the window hidden,
record and stop: red during capture, no success while processing, green only after
the text arrives, normal after five seconds. Repeat with sounds disabled, then
start a second recording while green and keep recording past the old timeout;
red must remain. Cancel a recording and induce a delivery failure: neither should
confirm success. Repeat on Linux and Windows. Automated tests and Actions packaging
do not establish that a real desktop shell displayed the colors.

## Quick installation

Linux:
```sh
curl -fsSL https://github.com/jli-software/utterform/releases/latest/download/install-linux.sh | sh
```

Windows PowerShell:
```powershell
irm https://github.com/jli-software/utterform/releases/latest/download/install-windows.ps1 | iex
```

Or [download the Windows setup EXE](https://github.com/jli-software/utterform/releases/latest/download/utterform-windows-x86_64-setup.exe).
These commands install/update the latest stable release, without preview flags.
