# Utterform 0.4.1 — Nothing waits forever, and better offline models

## A request always comes back

A Tauri command that panics never answers, and the interface then waits with nothing to show. That is how a single dependency conflict became "Transcribing…" that never ended in 0.3.3. The fix in 0.3.4 removed that particular conflict; this release removes the failure mode.

- Transcription, transformation and delivery run on their own task. A panic anywhere in them now reaches you as an error instead of silence.
- OpenAI requests are retried when repeating can help: rate limits, server faults, and connections that never completed. The wait grows between attempts and follows the server's own `Retry-After` when it sends one, capped at 20 seconds. A rejected key or a malformed request is not retried — it would fail identically every time.
- As a last resort the interface stops waiting after 30 minutes and says so. Local transcription of a long recording on a large model is slow but finite, so the limit is deliberately generous.

## Larger offline models

Settings now offers, alongside Tiny, Base and Small:

| Model | Download |
| --- | --- |
| Whisper Medium | 1.53 GB |
| Large v3 Turbo (compact) | 574 MB |
| Large v3 Turbo | 1.62 GB |

Large v3 Turbo is the most accurate offline option and fast for its size. The compact build is the same model quantized: close to the same accuracy at roughly a third of the download, which makes it the reasonable default on a laptop.

Every download is verified against SHA-256 as before. The checksums were taken from the published objects and the method was checked against all three existing models first: their recorded checksums match exactly.

## Verified

49 native tests and 35 interface tests. New: a panic inside a command produces an error rather than silence; which HTTP outcomes are worth repeating and which are not; that attempts are bounded and back off; that the server's `Retry-After` wins but stays capped; that the waiting ceiling passes results and rejections through untouched, fires with a readable message when nothing answers, and leaves no timer behind; that every model URL ends in that model's own file name.

Not verified here: an actual transcription with the new models, which needs the downloads and a microphone.
