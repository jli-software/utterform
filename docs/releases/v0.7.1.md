# Utterform 0.7.1 — macOS release

The first regular macOS release. Jonas confirmed 0.7.0 beta 1 on a MacBook Air (M2,
macOS 26) on 2026-09-10: the microphone dialog appears, GPT Transcribe and Local
Whisper transcribe, the dictation key works and can be changed in Settings, and
typing at the cursor arrives. Everything from the beta is in this release unchanged;
0.7.1 adds one correction for the Mac. Live Dictation on macOS is deliberately not
part of 0.7 and is planned for a later release.

## What was wrong

- **The Dock and the app switcher (⌘-Tab) showed the previous Utterform logo.** The
  bundle carries the current artwork — the Finder shows it — but macOS caches an
  application's icon and kept serving the one it had rendered for an earlier
  version installed at the same path under the same icon file name, `icon.icns`.

## What changed

- **The icon file is now `Utterform.icns`.** `CFBundleIconFile` names it, so the
  cached entry for `icon.icns` no longer applies and macOS renders the icon anew.
  The artwork itself is byte-for-byte the same as in 0.5.0 through 0.7.0.
- **Developer ID signing is prepared, not yet active.** The release workflow signs
  with a Developer ID certificate and has Apple notarize the app as soon as the
  repository holds the six secrets described in `docs/MACOS.md`; without them it
  keeps ad-hoc signing, as before. Nothing changes for this release.

## If the old logo is still shown

Then the cache outlived the rename. This confirms it either way: copy
`Utterform.app` to the Desktop, start that copy, and look at ⌘-Tab — a fresh path
gets a fresh cache entry. To clear the cache for the installed copy:

```bash
sudo rm -rf /Library/Caches/com.apple.iconservices.store
sudo find /private/var/folders -name com.apple.iconservices -exec rm -rf {} + 2>/dev/null
sudo find /private/var/folders -name com.apple.dock.iconcache -exec rm -rf {} + 2>/dev/null
killall Dock Finder
```

**Grants on update:** the bundle is still ad-hoc signed, so macOS asks for the
microphone again and the old Utterform entry under Accessibility must be removed and
the new one added. This ends once the app is Developer ID signed.
