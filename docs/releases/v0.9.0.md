# Utterform 0.9.0 — Settings, found at once

Settings had a Save button, long explanations and a sorting you had to know. You
changed something, forgot to save, and it was gone; or you did not find it at all.

**No Save button.** Every change applies the moment you make it. A text field waits for
a short pause in typing, and closing Settings writes whatever is still waiting. A small
**✓ Saved** confirms it. What cannot be stored — a vocabulary word with `<` or `>`, a
language that is not a code — stays at its field with the reason, and is not saved.

**Search first.** A search field sits on top. Type `key`, `mic`, `autostart` or `log`
and the matching settings from every category appear, ready to change right there.

**Five categories, one row per setting:**

| Category | Rows |
| --- | --- |
| Recording | Microphone, shortcut, sounds |
| Transcription | Engine (Cloud, Live, Local), OpenAI key, language, vocabulary, context, local model |
| AI | Actions, text model |
| Output | Type at cursor, keystroke delay, folder, history |
| App | Theme, start at login, diagnostics |

**Less to read.** Each row is a short name and its control; explanations are tooltips.
Details sit one level down: the list of local models, the text model and its effort,
an action's prompt. Vocabulary and languages are added one at a time with Enter and
removed with ×; a pasted list keeps its lines.

Nothing about recording changed, and existing preferences carry over untouched.
