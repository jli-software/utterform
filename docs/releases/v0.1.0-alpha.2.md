# Utterform 0.1.0 Alpha 2

Unsigned Linux x86_64 test build for Omarchy and Arch Linux.

Install without `sudo`:

```bash
curl -fsSL https://github.com/jli-software/utterform/releases/download/v0.1.0-alpha.2/install-linux.sh | sh
```

This build replaces the AppImage runtime from Alpha 1 with a system-linked package. It uses Omarchy's own GTK, WebKitGTK, Mesa, and EGL libraries consistently, preventing the `EGL_BAD_ALLOC` abort caused by mixing Ubuntu-bundled support libraries with Arch's graphics stack.

Required runtime packages:

```bash
sudo pacman -S --needed webkit2gtk-4.1 gtk3 alsa-lib libayatana-appindicator
```

The installer verifies SHA-256, checks for missing shared libraries before replacing an existing installation, installs below `~/.local/share/utterform`, and creates a desktop-menu entry and `~/.local/bin/utterform` launcher.

This alpha is unsigned. The microphone and OpenAI flows still require live testing on a desktop system.
