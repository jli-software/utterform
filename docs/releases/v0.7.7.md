# Utterform 0.7.7 — Clearer settings, less text

The recording window and Settings use less explanatory text. Navigation labels stand
on their own, closed selectors show the selected value, and option descriptions are
available when a menu is opened. Recording, paused and processing states remain visible
and accessible; delivery feedback, errors and missing-model guidance are retained.

## Settings by task

- **General:** appearance and startup.
- **Recording:** microphone, language hints, dictation shortcut, sounds, vocabulary and recording context.
- **AI & Models:** transcription mode, OpenAI key, local models, text model and thinking effort.
- **Actions:** built-in and custom prompts.
- **Output:** typing method, file folder and local history.

The transcription selector now matches the three choices in the main window. Settings
changes still apply on Save and revert on Cancel across all categories. Explicit
resource operations such as downloads, key removal and confirmed history clearing
remain immediate.

Cloud-processing notes, live cursor/focus restrictions, platform limitations and the
unencrypted-history notice stay near the controls they explain. Recording engines,
shortcuts, delivery and storage formats are unchanged.

## Verification scope

This is a frontend/settings change. Automated UI and production-browser checks cover
navigation, persistence, cancellation, shortcut/startup error routing, dark/light themes
and compact layouts. Browser tests use mocked desktop IPC; they do not establish native
Windows/macOS window rendering or physical microphone/input behaviour.

The release pipeline builds Linux x86-64, Windows x86-64 and macOS Apple Silicon.
The macOS app is Developer ID signed, uses the hardened runtime and carries a stapled
Apple notarization ticket. Windows remains unsigned. Verify downloads against
`SHA256SUMS.txt`; install the macOS DMG, Windows setup EXE or Linux system package
appropriate for your device.
