# Utterform 1.1.0 — The right microphone, one click away

*The first stable release since 0.8.0. It brings everything of the 1.0.0 release
candidate and adds the microphone to the tray menu. There is no separate 1.0.0.*

**Switch the microphone from the tray.** The headset for calls is plugged in, but you
want to talk to the laptop. Right-click the Utterform icon, open **Microphone** and pick
the laptop's microphone. The next dictation uses it, and it stays chosen until you pick
another one. **System default** follows the microphone your system uses and names it, so
you see at a glance which one that is. It is the same setting as Settings → Recording →
Microphone; both always agree.

Plugging a microphone in or out is noticed: on Windows and macOS the list is read again
as the pointer reaches the tray icon, and everywhere when the window opens. A chosen
microphone that is unplugged stays in the menu, greyed out, and recordings fall back to
the system default until it is back.

**Everything from 1.0.** A first-run assistant, Settings with search and no Save button,
text actions on your ChatGPT subscription (experimental), the Context action for the
selected text or the clipboard, an action per application and transcription of voice
messages and audio files. The details are in the
[1.0.0 release candidate notes](v1.0.0-rc.1.md) and in the changelog under 0.9.0 to
0.14.0.

## Install

Quit Utterform first.

- **Linux (Omarchy / Arch):**
  `curl -fsSL https://github.com/jli-software/utterform/releases/download/v1.1.0/install-linux.sh | sh`
- **Windows (PowerShell):**
  `irm https://github.com/jli-software/utterform/releases/download/v1.1.0/install-windows.ps1 | iex`
- **macOS:** the [DMG](https://github.com/jli-software/utterform/releases/download/v1.1.0/utterform-macos-aarch64.dmg),
  Developer ID signed and notarized.

Windows builds remain unsigned and may trigger SmartScreen. Verify downloads against
`SHA256SUMS.txt`.
