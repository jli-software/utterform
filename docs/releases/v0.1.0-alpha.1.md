# Utterform 0.1.0 Alpha 1

Unsigned Linux x86_64 test build for Omarchy, Arch Linux, and other current desktop distributions.

Install without `sudo`:

```bash
curl -fsSL https://github.com/jli-software/utterform/releases/download/v0.1.0-alpha.1/install-linux.sh | sh
```

The installer verifies the AppImage checksum, extracts it below `~/.local/share/utterform`, installs the `utterform` launcher below `~/.local/bin`, and creates a desktop-menu entry. Extraction avoids a runtime dependency on FUSE.

This alpha is unsigned. The microphone and OpenAI flows still require live testing on a desktop system.
