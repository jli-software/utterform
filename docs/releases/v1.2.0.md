# Utterform 1.2.0 — The microphone stays where you put it

**Hold the microphone level.** How loud a microphone records is set by the operating
system, and other programs change it without asking: Teams, Zoom and Chrome turn it up
and down on their own. Open Settings → Recording and switch on **Level**. It starts at the
level your microphone has now; move the slider to where it sounds right. From then on
Utterform keeps it there while it runs and sets it back within two seconds when something
else changed it — for dictation, for a call, for a video you record.

Switch it off and Utterform leaves the level alone again.

- **Windows:** the microphone chosen for recordings, otherwise the default one. It is the
  same level as in Sound settings → Input.
- **Linux:** the default input of PipeWire or PulseAudio.
- **macOS:** the default input.

A tip for USB microphones with knobs, such as the RØDE NT-USB: the knobs set what you
hear in the headphones. What is recorded is set here.

## Install

Quit Utterform first.

- **Linux (Omarchy / Arch):**
  `curl -fsSL https://github.com/jli-software/utterform/releases/download/v1.2.0/install-linux.sh | sh`
- **Windows (PowerShell):**
  `irm https://github.com/jli-software/utterform/releases/download/v1.2.0/install-windows.ps1 | iex`
- **macOS:** the [DMG](https://github.com/jli-software/utterform/releases/download/v1.2.0/utterform-macos-aarch64.dmg),
  Developer ID signed and notarized.

Windows builds remain unsigned and may trigger SmartScreen. Verify downloads against
`SHA256SUMS.txt`.
