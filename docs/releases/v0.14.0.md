# Utterform 0.14.0 — Set up in a minute

*Stage of the road to 1.0, merged into `main`; not released on its own. It ships with 1.0.*

Until now a new user met the main window and had to find Settings to make Utterform work:
the key, the engine, the language were all one click away but nobody said so. Now the first
start asks four short questions.

**Where to transcribe.** Cloud — GPT Transcribe, the most accurate, with an OpenAI key — or
on this device with Local Whisper, offline.

**The key or the model.** For the cloud, paste the OpenAI key; **Create key ↗** opens
OpenAI's key page. It goes into the system keyring. On this device, pick the model; Base is
recommended, and one already downloaded says so.

**The language.** Type a code such as `de`; the system language is already there, and the
field shows its name. Add names and terms Utterform should spell right, if you like.

**Text actions.** Use the ChatGPT subscription for Email, Polish, Context and the others,
marked experimental and offered only when the Codex CLI is signed in. Below it the
dictation key and start at login.

**Skip setup** on every screen ends the assistant for good and changes nothing. Whatever
it asks can be changed later in Settings, and every screen says so.

**Nothing before Finish.** Moving between the screens stores, downloads and registers
nothing. Finish stores the key, downloads the model, sets the dictation key and start at
login, and only then counts setup as done. If something fails — a download, a key another
program holds — the assistant goes back to where it is chosen and says why; Finish again
picks up where it stopped.

**Existing users** never see it: an upgrade keeps everything as it is.
