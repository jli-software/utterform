# Utterform 1.0.0 release candidate 1 — Say it, it's done

*A test version of 1.0, published as a prerelease. The stable version stays 0.8.0 until
this candidate has been checked on Linux, Windows and macOS; then the same build is
released as 1.0.0.*

Everything built since 0.8.0 comes together here for the first time in an installed app.

**Set up in a minute.** A new installation opens on four short screens: where to
transcribe, the OpenAI key or the local model, the language, and the ChatGPT subscription,
dictation key and start at login. Skip ends it, and nothing is applied before Finish.
Existing users never see it.

**Settings, found at once.** One page with a search field on top, categories as tabs and
one row per setting. No Save button: every change applies at once.

**Text actions on your ChatGPT subscription.** Clean, Polish, Email, Context and your own
actions can run through the Codex CLI login at no extra cost. Experimental, with no
fallback to the API key. Transcription keeps using the OpenAI key or the local model.

**Say what to do with the selected text.** The new action **Context**: select an email,
say "reply that Monday at ten works", get the reply at the cursor. Linux reads the
selection itself; Windows and macOS use the clipboard.

**The right action in every app.** Settings → Context → Per app gives an application its
own action for the dictation key, for example Email in Thunderbird. A short notification
says when it takes over.

**Voice messages and recordings.** Open an audio file with the folder button or `O`, drop
it on the window, use `utterform --file` or "Open with". WhatsApp and Telegram voice
messages, M4A, MP3, WAV, FLAC and more, up to two hours.

The details are in the changelog under 0.9.0 to 0.14.0.

## Install this candidate

Quit Utterform first.

- **Linux (Omarchy / Arch):**
  `curl -fsSL https://github.com/jli-software/utterform/releases/download/v1.0.0-rc.1/install-linux.sh | sh`
- **Windows (PowerShell):**
  `irm https://github.com/jli-software/utterform/releases/download/v1.0.0-rc.1/install-windows.ps1 | iex`
- **macOS:** the [DMG](https://github.com/jli-software/utterform/releases/download/v1.0.0-rc.1/utterform-macos-aarch64.dmg),
  Developer ID signed and notarized.

The normal download links keep pointing to 0.8.0. The checks for this candidate are in
[docs/plans/v1.0-acceptance.md](../plans/v1.0-acceptance.md).
