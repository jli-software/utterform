# Utterform 0.3.0

Speak once. Shape the text. Pause whenever you need.

## What's new

- **One visual identity:** a refined violet/blue microphone logo shared by the app, Settings, tray and Windows/macOS/Linux icon assets. The Utterform name stays.
- **Refined Settings:** a clean sliders symbol, subtle opening animation, themed section and local-model cards, plus custom microphone/model selectors. Keyboard focus stays in the dialog; reduced-motion preferences are respected.
- **Dated recent texts:** today's entries show local 24-hour time and elapsed minutes. Older entries show `DD.MM.YYYY`; hover over the result date for its full date/time. Dates are also shown in the history menu and recovered for existing entries without resetting history.
- **Pause and resume:** use the new button or **P** to pause without finishing. **Space** still finishes and **Escape** discards, also while paused. Paused speech is not stored and no silent gap is inserted. The native ten-minute limit now counts active recording time only.
- **Same living recording surface:** the microphone-responsive violet/blue ambience and background/close-to-tray behavior remain intact.

`SHA256SUMS.txt` covers all eight assets. The Linux package uses system libraries rather than an AppImage runtime.

Omarchy installation/update (finish any recording and quit the old app first):

```sh
curl -fsSL https://github.com/jli-software/utterform/releases/download/v0.3.0/install-linux.sh | sh
```

On macOS, drag Utterform from the DMG into Applications. **Builds are still unsigned and not notarized.** Gatekeeper may require **System Settings → Privacy & Security → Open Anyway** after the first launch attempt; Windows SmartScreen may also warn. Verify downloads and their checksums. Do not disable system-wide security protections.

## Compatibility and privacy

The application identifier, executable name and storage locations are unchanged. Existing settings, API keys, downloaded models and history are preserved. Automatic updates are not implemented; install this version explicitly.

A pause keeps the microphone device open for reliable cross-platform resuming, but discards paused samples before conversion or writing. The OS microphone-use indicator may therefore stay visible. A paused session stays paused across window hiding/app switches. Tray Quit discards it.

History remains local and unencrypted. GPT Transcribe sends audio to OpenAI; local Whisper keeps audio on the device, while optional text transformations send text to OpenAI. Pausing does not send anything, and temporary audio is deleted after processing or cancellation. Shortcuts remain window-focused, not global.

## Validation and known limitations

The release pipeline gates publication on tests and native packaging for all four targets. Automated checks cover Svelte/TypeScript, frontend/release-metadata tests, Rust tests, Rustfmt, Clippy and production-browser tests with synthetic IPC. Screenshots were inspected in light/dark and compact/reduced-motion modes. These checks do not replace interactive microphone, permission and desktop testing on each OS.

The previously observed intermittent Linux WebKit subprocess abort during shutdown remains unconfirmed and is **not claimed fixed**. See [validation details](https://github.com/jli-software/utterform/blob/main/docs/TESTING.md). Version 0.3.0 is a normal release, but the project remains in early development and the signing/auto-update limitations above still apply.
