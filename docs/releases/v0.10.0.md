# Utterform 0.10.0 — Text actions on your ChatGPT subscription

*Stage of the road to 1.0, merged into `main`; not released on its own. It ships with 1.0.*

Clean, Polish, Email and the other actions need a text model. Until now that was always
the OpenAI API, paid per request with your key. If you already pay for ChatGPT, that
subscription can now do the work instead.

**Settings → AI → Provider: OpenAI key | ChatGPT.** Choose ChatGPT and the actions run
on your subscription, through the login the Codex CLI keeps on your computer. Utterform
has no login of its own: install the [Codex CLI](https://developers.openai.com/codex/cli)
and run `codex login` once. Until then the row says **Needs `codex login`** with a
**Set up** link, and a recording with an action is stopped before it starts.

**Transcription does not change.** GPT Transcribe with your OpenAI key, or the local
Whisper model, stays as it is. Only the rewriting afterwards moves.

**Experimental.** OpenAI does not officially support other apps on this path and may
close it. Utterform says so next to the choice and does not hide a failure behind your
API key: if ChatGPT refuses, you see why and get the plain transcript, as with any
failed action. Switch back to *OpenAI key* to use the API again.

**Quick.** On `asus16` a Clean through ChatGPT took about 1.5–2 seconds, against 5–7
seconds for `gpt-5-mini` over the API with the same prompt.

**Text model** lists the models the Codex CLI offers. *Auto* takes the fastest one
(GPT-6-Luna today) and follows when OpenAI replaces it. Effort is Auto, Low, Medium or
High; the API's *Minimal* runs as Low here.

When the ChatGPT sign-in is about to expire, Utterform renews it and writes it back to
the Codex CLI's file, so the CLI stays signed in too. When the subscription's usage
limit is reached, the message says when it resets.
