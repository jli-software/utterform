# Utterform 0.11.0 — Say what to do with the selected text

*Stage of the road to 1.0, merged into `main`; not released on its own. It ships with 1.0.*

Until now Utterform only knew what you said. With the new **Context** action it also
knows what you are looking at.

**Select, speak, done.** Select an email, start a recording with *Context*, say
"reply that Monday at ten works for me", and finish. The reply arrives at the cursor —
in the email's language, with greeting and sign-off. What you said is the instruction;
the selected text is the material. Rewrite it, translate it, shorten it, answer a
question about it: whatever you ask.

**Read at the start.** The selection is read when the recording starts, while it is
still where you left it. On Linux Utterform reads the selected text directly; it does
not press anything in the other window. On Windows and macOS there is no such selection
to read without pressing Ctrl+C for you — which would stop a program running in a
terminal — so there Context uses the clipboard: copy the text first.

**When nothing is selected,** the clipboard is used instead — except Utterform's own
last text, which would otherwise come back as material every time. With neither, your
instruction runs on its own ("write a sentence that I'm working from home today"), and a
note says that nothing was selected.

**Settings → Context** has two switches, **Selection** and **Clipboard**, both on. The
transcription row that used to be called *Context* (what your recordings are about) is
now **Topic**, so the two are not confused.

**Only Context reads.** Plain dictation and the other actions never touch the selection
or the clipboard. The material goes to the text model you chose — OpenAI key or ChatGPT —
and nowhere else; it is capped at 20,000 characters. An instruction written inside the
material ("ignore all previous instructions…") is treated as text, not obeyed.

**Quick.** On `asus16` through ChatGPT, a reply to a short email took 1.9 seconds.
