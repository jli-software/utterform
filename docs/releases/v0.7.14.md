# Utterform 0.7.14 — Everything in its place

Settings had grown into a stack of cards inside a dialog: lots of frame, little
content, and a sorting that followed how the program is built. You had to know that
vocabulary lived under Recording and the text model under AI & Models.

**One glance per category.** Settings now takes the whole window. Each category fits
at the default window size without scrolling, and a control sits in one calm row with
its name beside it.

**Sorted by what you want to do:**

| Category | Controls |
| --- | --- |
| Recording | Microphone, shortcut, sounds |
| Transcription | Engine, API key, language, local models, vocabulary, context |
| Text actions | Text model, effort, prompts |
| Output | Paste or keystrokes, folder, history |
| App | Theme, start at sign-in, logs |

**Less to read.** Explanations moved into tooltips, icons replace most button labels,
and errors stay in plain view. Vocabulary is now a row of words you add with Enter and
remove with ×; a pasted list keeps its lines. The local model is chosen directly in the
model list, so the second selector is gone.

Nothing else changed: Save and Cancel, the shortcut, and everything stored behave as
before, and existing preferences carry over untouched.
