# Utterform 0.3.1 — Compact recording, clear completion

## Improvements

- Latest text starts collapsed. Copy remains available; expand to read the transcript, date and recent history.
- A brief checkmark/pulse confirms both automatic and manual clipboard writes, only after success.
- Responsive floating layout down to 360 × 400, with breathing room below Action and grouped Stop/Pause controls. Existing ambient motion and reduced-motion support remain.
- A quiet, distinct completion chime follows transcription, optional transformation and successful delivery. Stop still has its own click; failed transformations/deliveries do not sound success. Recording feedback can be disabled in Settings.
- macOS supports Apple Silicon only (macOS 11+). Fix the incomplete 0.3.0 bundle signature; verify the signed app again inside the DMG and ZIP. Ad-hoc signing is not Developer ID signing or Apple notarization; Gatekeeper approval can still be necessary.
- Faster iteration: push/PR CI validates on Linux without compiling desktop release packages. Manual builds can target one platform. Releases build Linux, Windows and macOS ARM together once and publish only after all three succeed.

## Downloads

Stable filenames: `utterform-linux-x86_64-system.tar.gz`, `install-linux.sh`, `utterform-windows-x86_64.exe`, `utterform-windows-x86_64-setup.exe`, `utterform-macos-aarch64.dmg`, `utterform-macos-aarch64.app.zip`, plus `SHA256SUMS.txt`.

Quit the running app before updating. Existing settings, local models and history are preserved. Windows remains unsigned; macOS is ad-hoc signed, not notarized.

## Scope and verification

Linux is the current hands-on testing priority. Automated UI/audio/clipboard tests use synthetic data; native Windows/macOS compilation and package verification are not equivalent to interactive microphone/desktop testing. The new completion sound still needs listening on the user's devices.

A small tray recording popup is documented as a proposed next step, not enabled in this release. Close-to-tray behavior is unchanged; see [the concept](../TRAY-POPUP.md).
