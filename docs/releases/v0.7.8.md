# Utterform 0.7.8 — Stable settings

**Unreleased branch preview — awaiting user acceptance on Linux.**

Settings keeps the same size and position when switching between General, Recording,
AI & Models, Actions and Output. The dialog adapts to the available window height,
not to the amount of content. Navigation, the header and Save/Cancel stay stationary;
long panels scroll internally. Reserved scrollbar space keeps fields aligned.

Compact windows keep their horizontal category navigation. Save/Cancel, recording,
models, typing and stored settings are unchanged.

## Preview workflow

Build the chosen first-test platform on the PR branch, review the Actions artifact,
and iterate before merging. For this preview only Linux x86-64 is requested.
After user acceptance and authorization to finalize, the tagged release builds all
three supported platforms. An explicit immediate full-release request can skip
manual preview. See [the test procedure](../DEVELOPMENT.md#preview-and-release-procedure).

## Verification scope

Production-browser regression checks cover stable bounds, internal scrolling,
viewport resizing and compact layouts, alongside existing navigation, dropdown,
Save/Cancel and theme tests. Browser IPC is mocked: native visual acceptance is
still required on the chosen Linux desktop. macOS and Windows builds and physical
microphone/input checks are deferred; no release is published by the preview run.
