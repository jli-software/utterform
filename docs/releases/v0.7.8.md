# Utterform 0.7.8 — Stable settings

Settings keeps the same size and position when switching between General, Recording,
AI & Models, Actions and Output. The dialog adapts to the available window height,
not to the amount of content. Navigation, the header and Save/Cancel stay stationary;
long panels scroll internally. Reserved scrollbar space keeps fields aligned.

Dictation shortcut now appears first in **General**, including its setup guidance and
registration errors. Recording keeps microphone, language, sounds, vocabulary and context.

Compact windows keep their horizontal category navigation. Save/Cancel, recording,
models, typing and stored settings are unchanged.

## Preview workflow

Changes are previewed on one chosen platform before merging and the full release.
The Linux layout preview was accepted by Jonas, who then requested the final shortcut
move and authorized this complete release. Future previews include a ready-to-run curl
command. An explicit immediate full-release request can skip manual preview.

## Verification scope

Production-browser regression checks cover stable bounds, internal scrolling,
viewport resizing and compact layouts, alongside navigation, shortcut capture/error
routing, Save/Cancel and theme tests. The Linux layout preview was tested on a real
desktop; automated browser IPC remains mocked. Physical microphone/input behaviour
and native Windows/macOS visual acceptance are not established by these browser tests.

The release pipeline builds Linux x86-64, Windows x86-64 and macOS Apple Silicon.
The macOS app is Developer ID signed with Hardened Runtime and a stapled Apple
notarization ticket. Windows remains unsigned. Verify downloads against `SHA256SUMS.txt`.
