# Utterform 0.13.0 — Voice messages and recordings

*Stage of the road to 1.0, merged into `main`; not released on its own. It ships with 1.0.*

Someone sends a two-minute voice message and you would rather read it. Or a meeting was
recorded on the phone. Utterform now takes the file and gives back the text, the same way
it does for a dictation.

**Four ways in.** The folder button next to Settings, or `O` in the window. Drag the file
onto the window: it shows **Drop to transcribe** with the action and engine that will be
used. `utterform --file <path>` from a terminal or a script. And **Open with → Utterform**
in the file manager, on Linux, Windows and macOS — Utterform is only added to that list,
it never becomes the default player for MP3 or WAV.

**Same result as a dictation.** The text lands in the history and on the clipboard, and
in a file when File is on. The chosen action runs on it — Clean, Summarize, Email, your
own. It is never typed at the cursor: no text field is waiting for a file. Several files
dropped or opened at once are done one after another.

**The formats people actually get.** WhatsApp and Telegram voice messages (`.opus`,
`.ogg`), iPhone and Android recordings (`.m4a`), MP3, WAV, FLAC, WebM, AIFF. Opus is
decoded by libopus, built into Utterform; nothing else has to be installed.

**Long recordings.** OpenAI accepts at most 25 MB per upload. Audio up to twelve minutes
goes up whole, as dictations always did; anything longer is sent in parts of about ten
minutes, each cut at the quietest moment in the half minute before the mark, and the
texts are joined. Local Whisper reads the whole file at once. The limit is two hours.

**Privacy.** With GPT Transcribe the decoded audio is sent to OpenAI, as for a recording;
with local Whisper it stays on the device. Utterform works on a temporary copy that is
deleted afterwards and never touches the original. The log records the codec, length and
outcome — never the file's name, path or contents.

**Measured on `asus16`.** An 11-second WhatsApp-style message (Opus, 16 kb/s): GPT
Transcribe 1.6 s, local Whisper Base 4 s, both word for word. A 13-minute file went up in
two parts (9:34 and 3:37) in 17 s, both parts ending on a full sentence.
