# Utterform 0.7.6 — Menu-bar workflow and a seamless recording cycle

Utterform now stays a menu-bar application on macOS, exposes the transcription mode
where recordings begin, and is ready for the next dictation as soon as the previous
text has been delivered.

## macOS menu-bar application

- Utterform no longer appears in the Dock or ⌘-Tab, whether its window is open or hidden.
- The tray remains the primary entry point; opening Utterform again from Finder, Launchpad or Spotlight reveals the existing window.
- Closing the window keeps Utterform, its shortcut and any recording running. Use **Quit** in the tray menu to end it.
- Packaging refuses a bundle that does not carry the native boolean menu-bar declaration.

The Apple-Silicon downloads remain Developer ID signed, hardened-runtime enabled,
accepted by Apple's notary service and distributed with a stapled notarization ticket.

## Transcription in the main window

The main window now switches directly between **GPT Transcribe**, **GPT Live
Transcribe** and **Local Whisper**. A choice is saved immediately and agrees with the
same settings shown in the Settings dialog. Compact windows keep both the Action and
Transcription selectors visible and keyboard accessible.

Local Whisper still uses the model selected under Settings. If no model is ready, the
main window points there instead of duplicating model management.

## Faster next recording

Utterform returns to ready immediately after transcription, transformation, history
and every requested output have finished. The Done chime continues independently. If
the next recording starts while it is still playing, Utterform silences the remaining
tail before scheduling the new Start cue so the previous completion cannot delay or
bleed into the next dictation.

## Verification and limits

The release is covered by native callback-level tests, interface tests and production
browser scenarios across full and compact layouts. The release pipeline builds Linux,
Windows and Apple Silicon and verifies the packaged macOS app's Developer ID signature,
Team ID, hardened runtime, microphone entitlement, stapled ticket and Gatekeeper status.

The menu-bar focus behaviour and a completion chime interrupted on a physical speaker
still benefit from real-device confirmation. Windows remains unsigned and may trigger
SmartScreen. Compare downloaded assets with `SHA256SUMS.txt` from this release.
