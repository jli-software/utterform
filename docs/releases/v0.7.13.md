# Utterform 0.7.13 — Nothing said is lost

A dictation is hard to repeat, so a failure after you have spoken should never
cost you the words. Until now it did: when transcription failed, the audio was
deleted along with the error message.

**A failed recording is now kept.** The main window offers **Try again** and
**Discard**. Trying again uses your current settings, so fixing a key or switching
to Local Whisper counts. The text goes to the clipboard and is saved to history,
never typed at the cursor, because the cursor is no longer where you left it. A
dropped connection or a busy service gets one quiet retry first. Up to five
recordings wait, oldest first; when a sixth fails, the oldest is given up. They stay
in the temporary recordings folder until they succeed, you discard them, or
Utterform quits. They do not survive a restart.

**A microphone that disappears no longer takes the recording with it.** When a
headset drops out, Utterform stops right away and transcribes what it has, saying
the text is partial. The green confirmation and Done sound stay off in that case.

**Nothing fails in silence.** A dictation started by hotkey usually has a hidden
window, so its errors went unseen. When Utterform's window is not in front, failures
and partial results now appear as a desktop notification. If notifications are
unavailable, the window opens instead.

**The Linux keyring can restart.** The Secret Service session was held for the life
of the app, so one daemon restart broke every later key read until Utterform was
restarted. It now reconnects. A keyring that cannot answer also no longer blocks the
start of a recording: the audio is captured and kept if the key is still unreadable
afterwards.

**Small things.** A recording with no speech ends with a calm note instead of an
error. Settings refreshes the microphone list and key status each time it opens.

Windows builds remain unsigned.
