# Utterform 0.8.0 — Omarchy's dictation key

Omarchy 4.5 has a dictation layer of its own. You choose a backend once, under
**Setup → Defaults → Dictation**, and Omarchy gives it the same two keys everywhere:
**Alt + Space** to start and finish, and **Right Alt** held down to talk. Until now
that list only offered Superwhisper and Voxtype.

**Utterform is now one of them.** On Omarchy the Linux installer registers it as a
backend. Open the Omarchy menu, go to Setup → Defaults → Dictation and pick
**Utterform**. Your own binding, such as `utterform --toggle` on Super + D, keeps
working alongside. Choosing another backend there hands the keys back.

The installer adds one row to your own Omarchy menu file,
`~/.config/omarchy/extensions/omarchy-menu.jsonc`, and leaves everything else in it as
it was; a backup sits next to it. Three small commands go next to
`~/.local/bin/utterform`. `omarchy-remove-dictation-utterform` removes exactly these
again, and Utterform stays installed.

**A short press is not lost.** Push-to-talk sends stop the moment the key is let go.
With a quick press that is while the microphone is still opening and the start sound
plays, and Utterform used to ignore that stop: the recording kept running. Now the
stop is kept and the recording finishes as soon as it runs. A toggle in that same
moment is still ignored, so a bouncing key cannot start and stop at once.

**Nothing starts by accident.** Omarchy asks the current backend to stop whenever
another one is chosen. That never starts Utterform. A key press that does have to
start Utterform hands over at once instead of holding Omarchy's dictation lock
while the app runs.

Windows and macOS are unchanged apart from the shared recording fix.
