# Utterform 0.3.2 — One instance, one click

## Improvements

- Utterform runs as a single instance. Starting it again from the app drawer, a launcher or a terminal reveals the window that is already running instead of adding a second app with its own tray icon and recording state. A hidden or minimized window is unminimized, shown and focused.
- A left click or double click on the tray icon opens Utterform directly on Windows and macOS; the right-click menu with **Show Utterform** and **Quit** stays unchanged.
- The Linux desktop entry declares the window class, so desktops that track running applications match the window to the launcher entry.

## Known limitation on Linux

**Corrected in [0.3.3](v0.3.3.md): this section was wrong.** The limitation belongs to libayatana-appindicator, not to Linux, and Utterform no longer uses it for its Linux tray. A left click opens the window there too.

Tray clicks never reach the application on Linux. The tray lives behind StatusNotifierItem via libayatana-appindicator, which exposes a menu and no primary activation, so no left click or double click can be observed — on Omarchy/Hyprland with Waybar included. Opening Utterform from the tray therefore stays a menu action: click the tray icon and choose **Show Utterform**, which is the first entry.

The reliable single gesture on Linux is the launcher: search for Utterform and press Enter. With this release that focuses the running instance rather than starting a new one.

## Downloads

Stable filenames: `utterform-linux-x86_64-system.tar.gz`, `install-linux.sh`, `utterform-windows-x86_64.exe`, `utterform-windows-x86_64-setup.exe`, `utterform-macos-aarch64.dmg`, `utterform-macos-aarch64.app.zip`, plus `SHA256SUMS.txt`.

Quit the running app before updating. Existing settings, local models and history are preserved. Windows remains unsigned; macOS is ad-hoc signed, not notarized.

## Scope and verification

Tray gesture handling and the packaged desktop entry are covered by automated tests. Whether a second launch focuses the running window, and how the tray behaves on a real desktop, needs hands-on checking on Omarchy; automated tests cannot observe a compositor. Recording, transcription and delivery are unchanged in this release.
